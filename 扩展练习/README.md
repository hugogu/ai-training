# 扩展练习

这些练习接在课程的模型训练与推理之后，用小实验理解模型怎样适应新任务，以及训练完成后怎样优化部署。

| 练习 | 主要问题 | 基础衔接 | 学习入口 |
|---|---|---|---|
| 图像分类微调 | 如何从已有 ResNet18 参数继续学习新的分类任务 | [前置知识](图像分类微调/前置知识.md) | [说明与运行方法](图像分类微调/README.md) |
| LLM 代码风格微调 | 如何用样例、SFT 和 LoRA 让已有语言模型适应回答习惯 | [前置知识](LLM代码风格微调/前置知识.md) | [说明与运行方法](LLM代码风格微调/README.md) |
| 模型量化 | 如何把 FP32 数值近似成低位表示，比较大小、质量和实际速度 | [前置知识](模型量化/前置知识.md) | [说明与运行方法](模型量化/README.md) |

每个目录有独立的依赖与 Notebook。微调关注通过训练改变模型行为，量化关注数值表示与执行方式；可以分别理解后再学习组合使用。

建议阅读顺序：每个练习先读“前置知识”，建立输入、模型、训练或转换的概念，再按 README 配置环境，最后结合代码注释运行 Notebook。视觉微调与 LLM 微调可对照理解训练循环；量化可以在完成任一推理练习后独立学习。
